Mean: a normalized N × N box kernel performs 2D low-pass convolution. Median: sort the N × N neighborhood and select its middle value; this is nonlinear. Larger windows can erase fine detail.
Gaussian: g = f + n, where n is a random Gaussian signal. Salt-and-pepper: randomly replace pixels with black or white impulses. These noise models are not LTI filters.
